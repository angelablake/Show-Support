# Show Support

Show Support is a plugin for WordPress that adds an emoji reaction button to your website. 

## Description

Visitors can show their support for you or your content by clicking the button and getting a burst of emojis. Each click adds to the click count, and you can optionally add a sound effect to the button.

- Sticky emjoji button for your site
- Animated burst of emojis on click
- Stats dashboard with daily, weekly, monthly, and content-level support insights
- Optional button sound effect
- Adjust size, color, and border
- No cookies or tracking
- Compatible with themes and page builders
- No cookies or tracking required

## Who it's for

Show Support is for anyone who wants to add a little joy and interaction to their WordPress website. It is most useful for personal sites and portfolios, where you can be a little quirky.

## Instructions

When these files are zipped and installed on a WordPress site as a plugin, the emoji button is automatically added to the front of your site and will appear on all pages.

### Installation

You can install the Show Support plugin with these steps:
1. From the repo's main branch, find Code, and select Download ZIP.
2. Inside your WordPress site admin, go to Plugins > Add Plugin, and find the Upload option.
3. Upload the zip file, and Activate it when it's finished uploading.

### Customization

You can update the appearance using these steps:
1. In your WordPress admin, find Appearance in the sidebar menu.
2. Under Appearance, navigate to Show Support.
3. In the Appearance tab of the Show Support settings, adjust the styles.

Styles you can adjust:
- Emoji: select between heart, star, grinning cat, and clinking beer mugs
- Sound effects: opt into a sound effect for your button
- Emoji size: set the size of your emoji in pixels
- Button padding: set the padding inside the button around the emoji in pixels.
- Background: set the background color of the emoji container in hex.
- Border width: set the width of the button border in hex.
- Border radius: give the button a curved border using pixels

Other settings you can control:
- Opt into data removal upon uninstall or reset the click count in the Utilities tab.
